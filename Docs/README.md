# VidOrient — product docs map

Controlled product documentation for this repo. Prefer these over inventing behavior from the README alone.

| Situation | Read | How much |
| --- | --- | --- |
| New feature / behavior change | [URD](./Requirements/URD.md), [PRD](./Requirements/PRD.md) | Relevant IDs / sections only |
| Architecture, APIs, processing, queue | [TDD](./TechDesign/TDD.md) | Matching `TDD-###` rows; PRD acceptance if changing contracts |
| New or restyled UI | [app style guide](./app-style-guide.md) | Full checklist before coding |
| After implementation | Same docs that should change | Update in the same change set |

Operator install/run/debug stays in the root [README](../README.md).
